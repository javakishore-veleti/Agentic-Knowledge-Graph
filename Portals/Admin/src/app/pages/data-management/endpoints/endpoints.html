Every endpoint names the environment variables that supply its values, never the values themselves. One row therefore works in local, Azure and AWS — they supply different values for the same names. Nothing secret is stored, so nothing secret can appear on this page or in an API response. Authentication varies by where the code runs: a named profile on a laptop, an attached role in EKS, keys in CI.
