Endpoints

One row per way of reaching a service. The same S3 bucket is a different endpoint depending on how you authenticate to it — a named profile on a laptop, an attached role in EKS, keys in CI — because that is a property of where the code runs.

Connection details hold names, never values. Non-secret facts sit at the top level; environment variable names sit under env. The database rejects a literal secret at either depth, so nothing on this page can be a credential.
